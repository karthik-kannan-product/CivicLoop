# LaunchLoop

LaunchLoop is the first CivicLoop agentic workflow loop: a human-approved event campaign launch assistant for small nonprofits.

Use the browser demo at `index.html`, or run the deterministic evaluator:

```powershell
python .\launchloop.py
```

Expected result: `16 / 16` eval cases pass and 100 labeled examples validate.

All data is synthetic. The loop prepares review-only drafts and validation evidence. It does not send, publish, schedule, change prices, create discounts, create audience segments, or export private data.
